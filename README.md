# federalhillsouth.org
An attempt to convert the Google Sites page to jekyll

There is an /embeds/ folder and this contains content that we can embed onto the Google Sites website.

## Map viewport

The map was freshly exported from OpenStreetMap on September 28, 2026,
with the north edge just beyond West Camden Street. SVG and JPEG output
are 936 × 811 pixels; the SVG and overlay viewBox is `0 0 882 764`.
The geographic export bounds (west, south, east, north) are
`-76.622315625, 39.264075264785895, -76.59014062499999, 39.28565`.

All overlay paths and labels are reprojected into this new Web Mercator
viewport. Adjacent regions share coordinates, including Otterbein/Federal
Hill. Otterbein and Sharp Leadenhall meet at a shared boundary without overlap.
Sharp Leadenhall extends south to West Ostend Street; Federal Hill extends
east to Key Highway and shares its southern edge there with Riverside.
